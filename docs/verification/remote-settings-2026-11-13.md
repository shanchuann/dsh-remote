# 远程控制设置页优化（2026-11-13）

## 改动

保留原有浅色、细边框卡片及品牌蓝配色，调整 `plugin/client/index.js` 中的远程控制设置页。

- 页面内边距 24px，卡片内边距 20px，卡片间距 16px；二维码与配对操作保持独立布局。
- 桌面按钮高度 36px，窄窗口下为 40px，复制按钮间距 10px。刷新过程中禁用刷新按钮，复制成功后更新按钮文字，失败时提供手动复制提示。
- Tailscale 地址与复制按钮并排显示，窄窗口下自动换行。Host 地址使用可选择的文本，不再链接到仅限本机访问的 `/pair`。
- 已配对列表按最近活跃时间降序显示最新五条，缺少活跃时间时使用创建时间；保留总数，不修改设备注册数据或认证接口。
- 页脚从 `/dsh-remote/state` 响应的 `pluginVersion` 和 `hostName` 读取实际插件版本与主机名，格式为“插件 <实际版本> Host <实际主机名>”，移除协议版本和分隔圆点。数据刷新时随之更新，文档和预览中的版本及名称仅为示例。

- 查看桌面浅色与 390px 深色完整页面，检查二维码、按钮、地址换行、设备行和页脚。
- 在 320px、390px、580px 和 820px 视口检查横向溢出，均未出现。
- 确认列表只显示五台最新设备，复制成功和剪贴板权限失败均有反馈。
- 确认空设备、无地址、未检测到 Tailscale 的提示和复制按钮禁用；模拟刷新 HTTP 503 后可重试恢复。
- Host 测试 102 项通过，含新增的设备展示顺序、不修改原始数组、空列表和页脚格式检查。分别使用 `0.1.17 / Office Host` 和 `0.2.0-beta.1 / 开发主机` 检查页脚动态字段，确认没有固定为示例版本或主机名。
- JS 语法及 Git diff 空白检查通过，Impeccable 检测未返回问题。
